# The Knowledge Priestess

The first Spirit of Knowledge in the plaza: a robed woman holding an open book to her
chest beneath a fan-shaped knowledge-graph halo, with a stepped crown and a brow jewel.
Retired because it read as priestly (the still frontal pose, the book held like scripture,
the halo and crown). Replaced by the Owl-bearer.

- `knowledge-priestess.glb`: the desktop model as it stood in the plaza (2048 WebP, meshopt).
- `knowledge-priestess-mobile.glb`: the phone copy.
- `knowledge-priestess.jpg`: the Grok render it was modelled from.

To show it again, copy the models back under `web/public/models/` and give it an
`ownPlinth` of `{ top: 3.58, cx: 0, cz: 0.1, height: 1.4, head: 9.0 }`.
